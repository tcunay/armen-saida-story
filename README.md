# Маленькая история Армена и Саиды

Короткая иллюстрированная новелла и открытка со стираемым золотым слоем. Работает на телефоне и компьютере, без сервера приложения, регистрации и внешних библиотек.

## Запуск

Откройте `index.html` или запустите в этой папке:

```sh
python3 -m http.server 8783
```

Затем откройте http://localhost:8783/.

## GitHub Pages

Публикуется из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll.

Тексты и длительность сцен находятся в `game.js`, оформление — в `style.css`, иллюстрации — в `assets/`. Исходные фотографии в комплект не входят.
